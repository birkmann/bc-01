Bandcamp, built in

Feed & fans

Follow artists and labels, walk the collections and wishlists of fans with your taste, and harvest new releases into an inbox.

Durable downloads

A job queue with leases and crash recovery. Files are tagged, synced and renamed atomically, and checked against what you already have.

Analysis

Tempo, beats and downbeats, Camelot key, energy, real EBU R128 loudness and a three-band waveform for every track.

06

Player

Gapless playback through a native real-time engine with EQ, filter, echo and limiter — plus media keys and a tray icon.

Your whole collection. No row cap.

bc sorts, filters and searches on the server, so the list holds your whole collection — not the first 500 rows. Jump anywhere and the page is there before you notice it loading.

Waveforms are measured on an absolute dB scale, so a quiet master looks quiet, and drawn on the GPU with the playhead at your display's refresh rate.

Bandcamp discovery

Explore: search Bandcamp and browse tag pages. Feed: new releases from followed artists and labels. Fans: browse other fans' collections. Liked releases go to the download queue.

Requests are rate-limited and cached. Responses are validated, including errors Bandcamp returns with a 200 status.

Plan a set. Let it mix.

Put tracks in a pool and Automix orders them by harmonic key and tempo and places mix points on phrase boundaries. Arrange lays the set out on two lanes: drag a clip edge to trim it, drag a transition to change how long it blends.

Play it live with the planner — up next, wishes and auto-fill — or render the whole set to a file.

Rust, all the way down.

One workspace of 23 crates, the interface included. The desktop app runs the server in-process and shows the UI in a Chromium app window; the same UI serves your phone and other browsers on your network, with device pairing.

  • Leptos interface, compiled to WebAssemblybc-ui
  • axum server with a typed WebSocket hubbc-server
  • SQLite in WAL mode, FTS5 search, one writerbc-db
  • Real-time audio engine on cpal, MPRISbc-engine
  • Decks, EQ, filters, echo, key lockbc-dsp · native + wasm
  • Tempo, key, loudness, waveformsbc-analysis
  • GPU waveforms, WebGL2 with Canvas2D fallbackbc-waveform
  • Bandcamp client, crawler and downloaderbc-bandcamp · bc-jobs

bc is an independent project and is not affiliated with or endorsed by Bandcamp. Support the artists you dig: buy the music you keep.

Get bc.

Builds from source and installs into ~/.local — no root needed.

$ git clone https://github.com/birkmann/bc-01.git bc
$ cd bc && ./scripts/install.sh
$ bc-desktop

Arch Linux

cd packaging && makepkg -si — installs bc-desktop, the bc-rust command line tool and the icons system-wide.

Requirements

Rust (stable) with the wasm32-unknown-unknown target, trunk, wasm-bindgen, brotli, ALSA, OpenSSL and D-Bus, plus Chromium, Chrome or Brave for the app window.

Phone & browser

bc-rust serve serves the same UI on 127.0.0.1:8420. Add --lan to reach it from other devices, each paired once.
